## ** Deliverables**

Participants are expected to submit the following deliverables:

### **1. Backend Service**
Participants should provide a backend service that:

- Accepts document input (PDF or image files)  
- Processes the uploaded document  
- Returns the predicted document category along with confidence score and processing time  

**Example Output:**
- **Document Type:** PAN Card  
- **Confidence Score:** 92%  
- **Processing Time:** 1 sec  

---

### **2. Project Documentation & Source Code**
Participants must submit the complete source code along with clear documentation explaining:

- System architecture  
- Steps required to run the project  

---

### **3. Documentation**
A short document describing:

- System architecture  
- AI models or APIs used  
- Instructions to run the project  
- Example inputs and outputs  

---

### **4. Demo Presentation**
Participants should present:

- A working demo of the system  
- Explanation of the solution approach  
- How the system achieves document classification accuracy  
- Possible future improvements or enhancements
